Security
========

CMP is a plain text format for chess moves.
It does not protect the data it stores.

Not Provided
------------

CMP does not provide:

* encryption
* authentication
* checksums
* key storage
* wallet backup

Do not treat a CMP value as secret or verified data.

Reporting Issues
----------------

Report bugs that can make two programs read the same CMP value differently.
Include the CMP value and the expected result.
