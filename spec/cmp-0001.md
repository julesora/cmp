CMP 1
=====

CMP 1 defines the cmp1 text format for legal chess move sequences.

Header
------

A value starts with cmp1 and at least one move:

    cmp1 e2e4 e7e5 g1f3 b8c6

Writers must use:

* lowercase text
* one space between words
* no leading or trailing space

Readers may accept mixed case and extra spaces.

Moves
-----

Moves use UCI:

    [a-h][1-8][a-h][1-8][qrbn]?

Examples:

    e2e4
    e7e8q
    e1g1

The last letter is the promotion piece.
Castling is stored as the king move.

Validation
----------

Start from the normal chess position.

For each move:

1. get the legal moves
2. require the move to be legal
3. play the move

Normal chess rules apply.
This includes check, castling, en passant and promotion.

Any invalid or illegal move makes the whole value invalid.

New Games
---------

If a game has ended and another move remains, start a new game.
There is no game separator in CMP 1.

Move Order
----------

When legal moves need an order:

1. convert each move to lowercase UCI
2. sort the strings in ASCII order

The start position has 20 legal moves.
The order is part of CMP 1.

Normal Form
-----------

The normal form is:

* lowercase
* the same moves
* one space between words
* no leading or trailing space

Do not replace UCI with SAN or PGN.

Output
------

Tools may convert CMP 1 to:

* UCI without cmp1
* SAN
* PGN

These are outputs, not CMP 1 values.

Each restarted game becomes a separate PGN game.
Finished games use their result.
Unfinished games use *.

Versioning
----------

cmp1 is the format version.
The Python package has a separate version.

A change to any of these needs a new CMP ID:

* text format
* chess legality
* new-game rule
* move order

Tests
-----

Test cases are in vectors.json.
The reference code is in cmp.py and chess_engine.py.
